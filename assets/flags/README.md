Country flags for the leaderboard card (`card_render.py`), one PNG per ISO 3166-1
alpha-2 code, lowercase (`us.png`). Bundled so renders never touch the network.

Source: flagcdn.com's 80px-wide set (https://flagcdn.com/w80.zip), from the
flag-icons project. Flags are public domain; flagcdn serves them free to use.
Only the two-letter country codes were kept (the zip's `gb-eng` and similar
subdivisions were left out, since the game stores two-letter codes).
